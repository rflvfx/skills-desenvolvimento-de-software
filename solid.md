# SOLID Principles

- **S** - Single Responsibility: uma classe, uma razao para mudar
- **O** - Open/Closed: aberto para extensao, fechado para modificacao
- **L** - Liskov Substitution: subtipos substituiveis pelo tipo base
- **I** - Interface Segregation: interfaces pequenas e especificas
- **D** - Dependency Inversion: depender de abstracoes, nao de concretos
